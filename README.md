# spotify-listening-insights-dashboard
A Power BI dashboard analyzing Spotify listening patterns using Python, pandas, DAX, and Power Query.


This project analyzes my Spotify streaming history using Python, pandas, and Power BI to uncover patterns in listening behavior. The dashboard visualizes total listening time, top artists/tracks, weekday trends, peak listening hours, and more.
It showcases skills across data cleaning, exploratory analysis, dashboard design, and KPI development.


Tech Stack
-Python
-Jupyter Notebook
-Power BI
-DAX Measures
-Power Query
